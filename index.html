Free · About 2 minutes · Your current settings are backed up first

Why

Powerful out of the box. Also a little reckless.

Claude Code can build almost anything. Left on its defaults, it can also delete a folder it shouldn't, burn through your plan on busywork, and forget what you agreed on yesterday.

Most people never change those defaults, because nobody tells them what to change. I use Claude Code every day and keep tuning it. This is that setup, packaged so you can have it in one step.

What you get

Five things change the moment you install it.

  • 01

    Brakes on the dangerous stuff

    Hard blocks on the commands that do the most damage, like wiping whole folders or overwriting your project's history. A built-in safety check stops other risky moves without asking you about every small step.

  • 02

    Your plan goes further

    Leaner instructions, the right model for each job, and habits that avoid wasted work. You get more done before you hit your limits.

  • 03

    It works like a careful professional

    Claude is set up to plan before it builds, reach for the simplest fix that works instead of piling on code, test what it made, and double-check before it says "done". When you're finished, type end session: it tidies the notes and saves everything, so the next session picks up where you left off.

  • 04

    Your private things stay private

    Rules that keep passwords and keys out of your code, and personal details off anything public.

  • 05

    It keeps getting better

    I update it as Claude Code changes and as better practices appear. Updates reach you automatically. You never reinstall anything.

How it works

Three steps. Claude does the setup.

  1. Copy the prompt below. One click.
  2. Paste it into Claude Code and press Enter.
  3. Read what Claude says it will change, then say yes. It does the rest and tells you when it's finished.
Paste this into Claude Code
Set up my Claude Code with https://github.com/Apurv-ed/best-claude-code-setup . First explain in plain words what it will change on my computer and wait for my OK. Then back up my current Claude settings, clone the repo and run its installer (python3 claude-setup.py), and tell me what changed.
What happens on your computer

Nothing changes until you say yes.

  • Claude explains every change in plain words first and waits for your OK.
  • Your current settings are saved before anything is touched.
  • Your own instructions to Claude are left alone. The new rules live in a separate file.
  • Changed your mind? Ask Claude to switch any part of it off.
Cheat sheet

What to type, once it's installed.

Bookmark this page. Inside Claude Code, type commands to see the same list.

Added by this setup

update docs
Checks and tidies this project's notes. Nothing goes to GitHub.
update github
Tidies the notes, then saves your work to GitHub.
end session
Wraps up: tidies all the notes, saves a handoff note if work is unfinished, then saves everything to GitHub.
deploy
Runs update github, then publishes the project if it has a publish step.
handoff
Writes a note so a fresh session continues where you left off. Use it once /context shows about 40% full.
ooc
Means "running out of context". Saves a handoff note right away.
read handoff
Continues from the last handoff note. Type it at the start of a new session.
grill me
Questions your plan until every decision is clear.
grade this
Checks the work against a checklist and improves it until it passes.
fix all tests
Fixes failing tests and re-runs them until they all pass.
commands
Shows this list inside Claude Code. /ap-optimal-claude:commands also works.

Built into Claude Code

/clear
Starts a new conversation with a clean slate. Use it between tasks to keep Claude sharp and save usage.
/resume
Reopens an earlier conversation.
/model
Switches to a different Claude model.
/usage
Shows how much of your plan you have used, and the cost.
/context
Shows how full this conversation is.
/rewind
Goes back to an earlier point in the conversation, with the option to undo code changes too.
/mcp
Manages add-on connections and their sign-ins. Sign in to Context7 (up-to-date library docs) once.
/doctor
Runs a checkup on your setup.

Keys and symbols

Esc
Stops Claude mid-answer so you can redirect it. Work done so far is kept.
Shift+Tab
Cycles through permission modes, including plan mode, where Claude plans before changing anything. On Windows, use Alt+M if Shift+Tab does nothing.
!
Runs a terminal command when typed at the start of a line. Claude sees the output.
@
Points Claude at a file. Type it, then pick the file from the list.
Questions

Before you paste.

Do I need to be technical?

No. You copy one prompt and answer yes when Claude asks. Claude handles every technical step and tells you what it did.

What do I need first?

Claude Code installed on your computer, with a Claude plan that includes it. That's all.

Does it work on Windows?

Yes, on Mac and Windows. On Windows a few of the automatic helpers need Git for Windows and Python. If they're missing, Claude will tell you and help you install them.

Is it free?

Yes. Free and open source.

How do updates work?

Automatically. New versions download in the background while you work and are active the next time you open Claude Code. There's nothing to click.

Can I trust it?

Every line is public on GitHub, so you or anyone you trust can read it. Every update is automatically checked for passwords and personal details before it goes out.

Can I undo it?

Yes. Your old settings are saved before anything changes. Ask Claude to restore them, or to turn off only the part you don't want.
